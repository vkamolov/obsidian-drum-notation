Agent skill · version 0.2.1

Printed drum scores, ready for Obsidian.

Turn clean printed drum-notation images or visible PDF pages into validated Obsidian Drum Notation blocks. The importer asks before guessing material ambiguities and includes a report for human review.

Open verification playground Get the GitHub release
Network-free plugin

The skill and validator make no network requests and send nothing to the developer.

Fail-closed transcription

Materially unclear instruments, timing, repeats, or navigation are questions—not guesses.

Human review required

Every transcription can contain errors. Review the score, notation, and import report before use.

Supported

Clean printed notation, visible PDF pages, grooves, practice material, and simple paired section repeats.

Not supported

Audio transcription, handwritten or unreadable scores, hosted inference, or silent vault writes.

Directory status

The 0.2.1 package is prepared for OpenAI directory review. GitHub installation remains available independently.
